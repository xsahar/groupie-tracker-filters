# Groupie Tracker

## Project Description
The Groupie Tracker project involves creating a user-friendly website with Go and HTML. It displays API data about artists, concerts, and dates, using data visualizations. An event/action system enables client-server interactions, emphasizing error handling and best practices, with unit tests included.

## Usage

1. **Clone the Repository:**
   ```bash
    https://learn.reboot01.com/git/sahahmed/groupie-tracker   
    cd groupie-tracker 
    ```

2. **Access the Web Interface:**
    ```bash
    access the web page by clicking on Server started at http://localhost:8080/ ,and it will take you directly to the webpage.
    ```
